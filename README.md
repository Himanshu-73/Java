console-based Java application designed to manage student records efficiently using Object-Oriented Programming (OOP) principles and dynamic data structures.
Student Categorization: Supports both Regular Students and Scholarship Students with distinct grading criteria via polymorphism.Full CRUD Operations:
Create: Add new students with duplicate ID prevention and mark validation ($0$ to $100$).
Read: Display all student records or search for a specific student by ID.Update: Modify student details (Name, Course, Marks) which automatically recalculates their grade.
Delete: Remove student records from the database.Interactive Menu: User-friendly, continuous loop menu driven by a do-while statement and switch-case logic.
